# Contributing

GuardZero projects take contributions through GitHub issues and pull requests.

1. Pick an open issue in [ValidFi](https://github.com/GuardZero144/ValidFi/issues), [sdk](https://github.com/GuardZero144/sdk/issues) or [docs](https://github.com/GuardZero144/docs/issues). Labels show the area (`contract`, `backend`, `frontend`), the difficulty and the priority.
2. Comment on the issue to ask for it to be assigned to you before starting.
3. Fork, branch from `main`, and keep each PR focused on one issue. Reference it with `Closes #N`.
4. Include tests for any behaviour you change, and make sure CI passes.

## Docs changes

Every page on this site has an **Edit this page on GitHub** link. To preview locally:

```bash
git clone https://github.com/GuardZero144/docs.git
cd docs
npm install
npm run dev
```
